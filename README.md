# zepto-analysis-dashboard

# Project Overview

This project analyzes Zepto sales data using Microsoft Excel to identify sales trends, revenue performance, category-wise contributions, city-wise sales distribution, discount effectiveness, and influencer marketing impact. The dashboard provides actionable insights for improving business performance and customer engagement.

# Objectives
-Analyze overall sales and revenue performance.
-Identify top-performing product categories.
-Compare sales performance across cities.
-Evaluate the impact of discounts on revenue.
-Measure influencer marketing effectiveness.
-Provide insights for business growth strategies.
